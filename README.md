# Análise de Dados: Evolução Global da COVID-19

## Sobre o Projeto
Este projeto realiza uma análise exploratória sobre os impactos da COVID-19, utilizando dados atualizados para entender a correlação entre medidas de saúde pública e a contenção do vírus. É um projeto que une minha experiência prévia em **Biomedicina** com as novas competências em **Sistemas de Informação**.

## Tecnologias e Ferramentas
*   **Python**: Pandas e NumPy para manipulação de dados.
*   **Matplotlib / Seaborn**: Para visualização de tendências e gráficos de dispersão.
*   **SQL (BigQuery)**: Caso tenha utilizado para filtrar os dados brutos antes da análise.

## Principais KPIs Analisados
*   Taxa de Letalidade por Região.
*   Progresso da Imunização vs. Queda no número de óbitos.
*   Média Móvel de novos casos.
