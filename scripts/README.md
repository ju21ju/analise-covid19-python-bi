# Scripts de Análise em Python

Esta pasta contém os algoritmos desenvolvidos em Python para o processamento dos dados da pandemia. 

## O que cada script faz:
*   `analise_covid.py`: Script principal que realiza a limpeza dos dados e gera as métricas de vacinação.
*   `extracao_dados.py`: Script principal em Python responsável por conectar-se à fonte de dados e realizar a extração inicial.
*   `extracao_dados1.py`: Versão refinada do script de extração, contendo ajustes de performance ou novos filtros de busca.

## Bibliotecas Utilizadas
Estes scripts foram desenvolvidos utilizando as bibliotecas **Pandas** para manipulação de dados e **Matplotlib/Seaborn** para a geração de gráficos, conforme os padrões aprendidos no curso de Python da FIAP.
